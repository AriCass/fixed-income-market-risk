# Fixed Income & Market Risk Analytics

## Overview
This project develops a Python-based quantitative analytics framework for fixed income valuation and market risk measurement. It focuses on bond pricing, yield calculations, interest rate sensitivity, portfolio risk, and scenario analysis.

## Objectives
- Price fixed income instruments based on discounted cash flows.
- Calculate yield to maturity (YTM).
- Measure interest rate sensitivity using duration, convexity, and DV01.
- Analyze fixed income portfolios.
- Estimate Value at Risk (VaR) and Expected Shortfall (ES).
- Perform interest rate stress testing and scenario analysis.
- Develop visualizations to support risk monitoring.

## Methodology
The project will be developed incrementally, combining financial theory, numerical methods, data analysis, and Python programming. Results will be validated through mathematical checks and test cases.

## Technologies
- Python
- NumPy
- pandas
- SciPy
- Matplotlib
- Jupyter Notebook
- Git / GitHub

## Project Structure
- `notebooks/`: financial analysis and model development
- `src/`: reusable valuation and risk functions
- `data/`: datasets
- `tests/`: calculation validation
- `reports/`: charts and outputs
